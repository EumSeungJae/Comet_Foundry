# Comet Foundry — 첫 플레이 버전

2026-10-14

## 실행

- Unity: `Assets/CometFoundry/Scenes/FoundryPlayableScene.unity`를 열고 Play.
- 메뉴: `Comet Foundry > Open Playable Scene`.
- Windows 빌드: `Builds/CometFoundry/CometFoundry.exe`. 같은 폴더의 데이터와 DLL도 함께 유지한다.

## 플레이

1. 기존 생산 건물을 클릭한다. 팝업에서 생산품을 선택한 뒤 **이 생산품으로 설정**을 누른다.
2. 왼쪽에서 시설을 선택하고 빈 타일을 클릭해 건설한다. 채굴기는 철·구리·얼음 노드 위에만 배치할 수 있다.
3. 드론은 빈 통로로 접근 가능한 건물 사이에서 재료를 자동 운반한다. 생산 입력, 판매 완제품, 창고 보관 순으로 배정한다.
4. 재료·솔라·보관 공간이 충분하면 생산한다. 부족하면 진행도를 유지하고 대기한다. 전력이 부족하면 생산·물류·판매가 멈춘다.
5. 거래소 터미널은 5등급 완제품을 받아 기준가로 판매한다. 오른쪽에서 자동 판매를 켜거나 끌 수 있다.
6. 산업장비 5스택 납품이 첫 목표다. 완료 후에도 계속 건설하고 생산할 수 있다.

시작 시설은 철·구리 채굴기 2개, 소형 창고, 대형 발전소다. 시작 자금은 80,000솔라다. 새 튜토리얼에서는 추가 채굴기부터 건설하고, 원자재를 정제·가공·조립하는 과정을 직접 진행한다.

생산품을 바꾸면 진행도가 초기화되지만 기존 재료는 보관된다. 같은 생산품을 다시 선택하면 진행도가 유지된다. 재료와 생산 비용은 **완성 시 한 번에 차감**한다. 완성품 전체를 보관할 수 없으면 재료를 소비하지 않는다.

**산업장비 생산 경로:** 철광석 → 철괴 → 철판/기어 → 프레임 → 기계부품, 구리광석 → 구리괴 → 구리선 → 회로기판 → 전자부품. 기계부품과 전자부품을 산업장비로 조립한다. 여러 품목을 동시에 생산하려면 가공소와 조립소를 추가하고 전력도 확충한다.

## 조작과 저장

- 건물 클릭: 생산품 설정 또는 재고/시설 정보 팝업.
- 빈 타일 클릭: 선택한 시설 건설.
- Esc: 팝업 닫기 / 건설 취소 / 새 게임 확인 취소.
- 보드 우클릭: 건설 취소.
- Space: 일시정지 / 기본 속도로 재개.
- 1× / 4×: 시뮬레이션 배속.
- 저장 / 불러오기: 로컬 PlayerPrefs에 단일 슬롯 저장. 오프라인 생산은 계산하지 않는다.
- 새 게임: 두 번 눌러 현재 플레이를 초기화. 저장 버튼을 누르기 전까지 기존 저장은 유지한다.

## 구현 범위

16종 자원, 16종 레시피, 9종 건설 시설, 고정 16×12 시작 혜성, 채굴과 한정 매장량, 시설별 재고, 전력, 드론 자동 운송, 완제품 판매, 목표, 배속, 저장 복원을 연결했다. 건물 그래픽은 흰색 외장과 주황색 식별 마킹을 사용하는 투명 배경 128×128 그래픽이다.

이번 장면의 드론 운송은 한 건씩 배정한다. 통행 가능 여부는 기존 드론 경로 시스템으로 계산하지만, 화면 이동 표시선은 두 건물 사이의 직선이다. 거래 가격은 초기 기준가로 고정한다. 월드 혜성 확장·화물선·연구·지구 뉴스·시세 변동·건설 재료 자체 조달 할인은 기존 프레임워크에 남겨두었으며 이번 장면에는 연결하지 않았다.

## 검증

- 런타임 코드 빌드: 오류 0, 경고 0.
- Unity 내부 시뮬레이션 검증: 채굴, 운송, 생산, 판매, 출력 공간 부족, 비용 보존, 생산품 변경, 건설, 저장 복원 통과.
- 신규 EditMode 테스트 8개 모두 통과. 전체 생산 체인을 구축해 산업장비 5개 납품 목표에 도달하는 시나리오 포함.
- 전체 기존 테스트 포함 55개 중 50개 통과, 5개 실패. 실패는 기존 혜성 생성 범위 오류 1개, 거래 가격 기대값 불일치 2개, 시장 이벤트 부동소수점 비교 1개, 의뢰 갱신 기대값 불일치 1개다. 해당 시스템은 이번 플레이 장면에서 사용하지 않는다.

개발용 검증 메뉴는 `Comet Foundry > Validate Playable Game`, 빌드 메뉴는 `Comet Foundry > Build Windows Playable`이다.


## 타이틀 화면과 폰트 (2026-10-08)

시작 시 커버 이미지의 로고를 보존한 타이틀 화면을 표시합니다. 새 개척 시작, 저장한 개척 불러오기, 종료를 선택할 수 있습니다. 게임의 타이틀 버튼으로 돌아오면 개척 재개와 새 개척 시작이 표시됩니다. 새 개척은 현재 진행 초기화 확인을 거치며 기존 저장은 저장 버튼을 누르기 전까지 유지됩니다. 타이틀을 표시하는 동안 시뮬레이션 시간은 멈춥니다.

넥슨 메이플스토리 Light/Bold TTF를 Resources에서 로드하여 본문·버튼·제목에 사용합니다. 폰트는 `Assets/CometFoundry/Resources/Fonts/NEXON_Maplestory`, 커버는 `Assets/CometFoundry/Resources/Title/CometFoundryCover.jpg`에 있습니다. `-foundryCapture <폴더>` 실행 시 title.png도 캡처합니다.


## 게임 날짜와 월간 경영 지표 (2026-10-08)

상단에서 게임 날짜를 확인합니다. 개척 1년 1월 1일에 시작하며 1개월은 30일, 1년은 12개월입니다. 게임 1일은 기본 속도에서 5초입니다. 월간 시세 및 소지금 갱신은 150초마다 발생합니다. 저장한 경과 시간으로 날짜가 복원됩니다.

거래소의 실제 시세·구입·판매 단가는 30일마다 갱신됩니다. 일반 시세는 정가 대비 ±30%이며 월 중에는 가격이 고정됩니다. 현재 플레이 버전에는 시장 이벤트가 구현되어 있지 않습니다. 자원 그래프는 30일 간격의 가격 기록을 부드러운 곡선으로 연결하고 전월 대비 금액·변동률과 다음 갱신까지 남은 일수를 표시합니다. 개척 전 시세는 기존처럼 조회 가능하며 축에 개척 전 기간을 표시합니다.

소지금 그래프는 시작 소지금과 이후 매월 1일의 실제 소지금을 기록합니다. 월 중 거래·건설은 기록된 월초 값을 변경하지 않습니다. 현재 소지금은 별도로 실시간 표시하고, 월간 비교는 월초 기록끼리 계산합니다. 30일 경과 후 첫 월간 비교가 표시됩니다. 이전 저장의 기록은 그대로 유지합니다.


## 철거·팝업 안내·거래소 미션 (2026-10-08)

임시로 자원별 자동 발생하던 시장 이벤트를 제거했습니다. 실제 시장 이벤트를 구현하기 전에는 모든 시세가 정가 대비 ±30%를 초과하지 않습니다. 가격 그래프는 곡선 표시와 30일 갱신을 유지합니다.

왼쪽 시설 철거 → 건물 클릭 → 확인, 또는 생산 팝업의 철거 버튼으로 철거합니다. 재고는 같은 혜성의 다른 창고·항구·거래소로 이동합니다. 보관 공간 부족 또는 수송선이 이용 중인 선착장인 경우 철거를 막습니다. 건설비는 환불되지 않습니다. 철거 후 타일을 다시 사용할 수 있습니다.

개척 시작·저장 불러오기 시 팝업으로 안내 여부를 선택합니다. 현재 튜토리얼은 아래 2026-10-14의 14개 주제를 순서대로 안내합니다. 상단 튜토리얼 버튼으로 처음부터 다시 실행할 수 있습니다. 저장 불러오기는 타이틀에 있습니다.

기존 튜토리얼 HUD는 미션 진행 영역입니다. 거래소 건설 후 미션받기로 10개 납품 미션 중 하나를 수주합니다. 동시에 한 미션만 진행하며 기한은 없습니다. 전체 혜성의 시설 재고를 합산하고 미션 납품 버튼으로 필요한 자원만 차감하여 보상을 지급합니다. 완료 보상은 한 번만 받을 수 있습니다. 수주 취소는 재고를 소비하지 않습니다. 수주·완료 상태는 저장·불러오기에 포함되고 이전 저장도 지원합니다.


## 2차 가공 미션 실습과 드론저장소 (2026-10-08)

미션은 철판·구리선 등 가공 등급 2 이상 품목으로 10개를 제공합니다. 원재료/1차 가공품 미션은 수주할 수 없으며, 기존 저장의 진행 중인 구형 철괴 미션은 해제합니다. 완료된 구형 미션 기록은 저장 호환을 위해 유지합니다. 전체 목록: `ExchangeMissions.md`.

이전 철판 생산 실습의 저장 호환은 유지합니다. 신규 튜토리얼은 생산 실습과 미션 설명을 순차 안내에 통합하며, 시작할 때 이전 실습 안내를 종료합니다. 기존 수주 미션과 재고는 유지합니다. 새 튜토리얼의 생산 단계에서는 해당 시설의 실제 생산 완료를 확인합니다. 미션 단계에서는 생산 또는 거래로 재고를 확보한 뒤 납품합니다.

## 노란 타깃 박스와 순차 튜토리얼 (2026-10-14)

각 세부 단계는 별도의 지시 팝업을 띄우고 현재 조작 대상 또는 설명 영역에 노란 박스를 표시합니다. 팝업은 타깃을 가리지 않는 위치에 표시됩니다. 모든 행동 단계는 추가 튜토리얼 확인 버튼 없이 바로 조작하고, 실제 완료 조건을 만족하면 자동 진행합니다. 건설은 새 시설 객체가 해당 혜성의 보드에 실제 배치되었는지 검사하며, 철거 후 재건설로 시설 수가 같아도 완료를 감지합니다. 설명 전용 단계만 `확인 · 다음 설명`으로 진행합니다. 실제 생산품 설정·거래 실행 버튼은 해당 게임 기능을 수행하는 버튼입니다.

1. 채굴기 건설과 철광석 원자재 생산.
2. 정제소 건설과 철괴 1차 자재 생산.
3. 금속 가공소 건설과 철판 2차 자재 생산.
4. 구리괴 공급, 전자 가공소 건설, 구리선 9스택 및 회로기판 2스택 생산. 구리선은 2차 소재, 회로기판은 3차 소재입니다.
5. 일반 조립소 건설과 전자부품 4차 자재 생산. 기계부품 및 완제품 조합도 소개합니다.
6. 창고의 보관·지원 물류와 항구의 입출항·하역 기능.
7. 드론 격납고의 자동 물류와 발전소의 혜성별 전력 공급.
8. 거래소 터미널 건설.
9. 보유 소재, 시장 시세 차트, 구매와 판매 실습.
10. 미션 목록, 수주, 재고 확보, 납품과 보상 지급.
11. 혜성관리의 보유 혜성, 개인자금 변동지표, 탐사·개척, 수송선 관리.
12. 실제 혜성 구매: 탐사 시작 → 탐사 완료 → 후보 선택 → 비용 지불 및 소유권 확보.
13. 실제 혜성 간 이동: 새 혜성 선택 → 개발 구역 확인 → 출발 혜성 복귀. 화면 전환만으로 물자는 이동하지 않습니다.
14. 실제 물자 이동: 출발 혜성에서 물 3스택 확보 → 수송선 관리 → 출발·도착 혜성 및 화물·수량 선택 → 출항 → 실제 하역 완료 → 도착 혜성 항구 재고 확인. 항구가 가득 차면 안내는 하역 완료까지 기다립니다.

생산시설은 시설 선택 → 건설 → 건물 클릭 → 생산품 선택 → 생산 설정 → 실제 생산 확인으로 세분화합니다. 채굴기는 자원 노드와 일치하는 생산품이 자동 설정됩니다. 시설 선택 및 배치 단계의 `기존 시설 사용`은 이미 건설한 시설로 실습을 이어갑니다. 구매 재고는 생산 확인을 대신할 수 없습니다.

튜토리얼 안내 종료는 현재 게임 진행을 유지합니다. 개척 진행과 미션 상태는 기존 저장 기능을 사용하며, 새 안내의 세부 팝업 위치는 저장되지 않습니다. 불러온 게임에서 튜토리얼을 시작하면 첫 주제부터 기존 시설을 활용할 수 있습니다.

1×2 드론저장소를 시설 목록에 추가했습니다 (1,800 솔라, 수용 드론 8기). 기존 2×2 격납고와 별도 시설이며, 드론 지원시설이 없을 때 물류를 활성화합니다. 전력 부족과 막힌 통로는 별도로 해결해야 합니다. 보드 상단과 드론 지원시설 팝업에서 물류 상태를 확인할 수 있습니다. 시설/미션 목록은 스크롤하여 끝까지 볼 수 있습니다.

일부 혜성에는 2×3 대형 발전소를 놓을 연속 공간이 없습니다. 기존 1×1 소형 발전소(전력 4, 2,000 솔라)를 건설 목록에 추가하여 좁은 땅에서도 여러 기로 필요한 전력을 확보하도록 보완했습니다. 드론저장소만 건설해도 전력 부족은 해소되지 않습니다.
