# 드론 병렬 물류 규칙 (2026-10-14)

소형 드론 저장소(1x2)는 4대, 중형 드론 격납고(2x2)는 8대가 동시에 일한다. 소형 1개와 중형 1개는 총 12대다. 드론 4대당 전력 1을 사용하므로 소형은 1, 중형은 2가 필요하다. 창고와 항구에는 운송 인력이 없다. 새 게임에는 소형 드론 저장소 1개가 명시적으로 배치된다. 기존 저장도 불러오면 시설 정의에 따라 소형 4대·중형 8대를 적용한다.

생산 건물에는 미완료 입고와 출고를 합해 최대 2개의 작업만 배정한다. 초과 작업은 예약하지 않고 다른 건물을 검사한다. 배송이 끝나면 건물의 대기열은 해제되고 드론은 복귀를 마친 뒤 새 작업을 받는다. 긴급한 생산 재료, 작업 종류, 실제 대기시간에 따른 우선순위를 유지한다.

드론은 지원시설·출발지·도착지 사이의 실제 통행 가능한 타일 경로를 따른다. 전력 부족, 통로 단절, 출발 재고 부족, 목적지 공간 부족, 지원시설 부재에서는 배정되지 않거나 진행이 정지한다. 광물 자체 채굴과 혜성 간 수송선은 내부 드론 운송과 별개다.

빈 타일이 상하좌우로 연결되어야 하며 대각선만 맞닿은 틈, 건물, 손상된 공간은 통과할 수 없다. 건물 사이에는 최소 폭 1칸의 통로를 남긴다. 신규 혜성은 등급별 활성 비율 100/98/96/94/92/90/88%를 적용하고 외곽만 손상시켜 내부 통로를 보존한다. 건설 전에는 모든 활성 타일이 연결되지만 건물 배치로 통로를 막으면 운송할 수 없다. 기존 저장 지형은 자동 복구하지 않는다.

화면에는 모든 작업 드론과 이동 경로, 드론 번호, 운송 중 화물을 표시한다. 회수 이동은 어두운 색, 배송은 주황, 복귀는 초록이다. 상단은 전체 작업 수/보유 수, 지원시설 창은 해당 시설의 작업 수/보유 수(4 또는 8), 생산 창은 대기열 수/2를 표시한다. 수요가 적으면 일부 드론은 정상적으로 대기한다.

재고는 배송 시 원자적으로 이동한다. 진행 중에는 예약량을 빼고 다음 작업을 배정하여 재고와 공간을 중복 예약하지 않는다. 철거·경로 차단으로 취소되거나 저장 후 불러오더라도 운송 중 물자가 유실되거나 복제되지 않는다. 저장 형식 버전은 그대로 유지한다.
