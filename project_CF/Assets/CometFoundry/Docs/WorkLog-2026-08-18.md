# Work Log - 2026-08-18

## Request System

- Added exchange request generation and completion flow.
- Exchange requests refresh every 30 in-game minutes.
- Open request count grows from 3 to 6 by exchange trust level.
- Trust level controls request difficulty ranges:
  - Lv.0: 0~2
  - Lv.1: 1~3
  - Lv.2: 2~4
  - Lv.3: 3~5
- Request difficulty controls delivery item count and required processing grade.
- Request rewards use market price multiplied by `1.2 + trustLevel * 0.1`.
- Exchange trust experience and leveling rules were added.

## Resources And Currency

- Added resource processing grades.
- Added resource market tags, including `MilitaryGoods`.
- Recorded the current resource pool in `ResourcePlan.md`.
- Removed alien-material ore from the resource direction.
- Added the nitrogen crystal chain:
  - 질소결정 -> 액화질소 -> 냉각재 -> 극저온 부품
- Added elastic polymer as the rubber replacement:
  - 탄소분말 + 수소연료 + 액화질소 -> 탄성폴리머
- Chose `솔라` as the official currency name and `SOL` as its code.
- Kept internal `Credits` for compatibility, and added `CompanyState.Solar` plus `Currency`.

## Market And Events

- Added trust-based exchange buy/sell multipliers:
  - Lv.0: buy 1.75, sell 0.5
  - Lv.1: buy 1.5, sell 0.6
  - Lv.2: buy 1.25, sell 0.7
  - Lv.3: buy 1.0, sell 0.8
- Added dynamic resource price movement.
- Normal market prices stay within 70%~130% of base price.
- Default market price refresh interval is 1 in-game day.
- Added market events:
  - War rumor temporarily raises military goods.
  - Confirmed war raises military goods by 30%~80% per stack.
  - Confirmed war starts at 1 stack and can rise to 3 stacks.
  - War end chance is 20%, 40%, 80% at stacks 1, 2, 3.
  - Event refresh interval is 14 in-game days.

## Transport And Drone Logistics

- Added cargo ship ownership types:
  - Player owned
  - Rented
  - Exchange consignment
- Rented ships expire after a rental period.
- Player-owned ships can change speed multiplier.
- Ship durability drain scales with speed multiplier.
- Default time scale is real-time 5 minutes = 1 in-game day.
- Reframed comet-internal logistics around drones.
- Drone hangar rules:
  - Size 2x2
  - Base power consumption 0
  - Max drones 32
  - Max dedicated links 8
- Drone dedicated links connect hangar, source building, destination building, resource, and assigned drone count.
- Drones can move through active non-building tiles.

## Facilities And Power

- Added a prototype facility catalog with approved building sizes.
- Added power plants:
  - Small: 1x1, output 4
  - Medium: 1x3, output 16
  - Large: 2x3, output 32
- Normal buildings consume 1 power per occupied tile.
- Logistics drones consume 1 power per 4 drones.
- Added warehouse facility support.
- Prototype warehouse is 2x2 with 500t storage.

## Conveyor Path

- Reworked conveyors as drone paving paths.
- Conveyor paths are 1x1 tile occupants.
- Buildings cannot be placed on conveyor paths.
- Drones can move through conveyor paths.
- Fully paved dedicated drone routes get x1.2 speed.
- Conveyor path build cost starts at 300 솔라 per tile.

## Comet Resource Nodes

- Resource nodes now use total stack count instead of quality.
- Added stack weight to `ResourceDefinition`.
- `ResourceDeposit` stores initial and remaining stacks.
- Deposit ton values are derived from stack count and resource stack weight.
- Added comet-grade maximum resource stack rules:
  - F: 900
  - E: 2,000
  - D: 5,000
  - C: 12,000
  - B: 30,000
  - A: 80,000
  - S: 200,000
- Total stacks split into 1~6 resource nodes.

## Stack Logistics Update

- Internal logistics now use stacks as the main unit.
- `Inventory` exposes `CapacityStacks`, `UsedStacks`, `FreeStacks`, `AddStacks`, `RemoveStacks`, and `HasStacks`.
- Existing `Tons` names remain as compatibility aliases for older code.
- Exchange request delivery amounts now use `RequiredStacks`.
- Cargo movement and route checks now use stack capacity.
- Added `DroneHaulRequest` and `DroneWorkPlanner`.
- Drone work priority is production input first, market reservation second, storage third.
- Stack weight remains only as a reference/display value, not an internal logistics constraint.
