## Important Chains

- 얼음 -> 물 -> 수소연료
- 질소결정 -> 액화질소 -> 냉각재 -> 극저온 부품
- 탄소질 광석 -> 탄소분말 -> 탄성폴리머
- 탄소분말 + 수소연료 + 액화질소 -> 탄성폴리머
- 희귀 결정광 -> 결정 조각 -> 센서 -> 항법장치 -> 항성 항법 코어
- 우라늄광석 -> 우라늄봉 -> 반응로 부품 -> 소형 반응로

## Stack Logistics

- 내부 물류, 창고 용량, 드론 운반량, 의뢰 납품량은 스택 기준으로 계산한다.
- 자원 정의의 스택당 무게는 UI, 세계관 설명, 후반 외부 운송 확장용 참고값으로만 둔다.
- 채굴기는 분당 스택 생산량으로 밸런싱한다.
- 자원 노드는 품질 대신 총 스택 수를 가진다.

## Reference Stack Weight

- 자원 노드는 품질 대신 총 스택 수를 가진다.
- 자원 정의는 스택당 무게를 가진다.
- 창고, 화물선, 드론 적재량은 무게 기준으로 계산한다.
- 채굴기는 분당 스택 생산량으로 밸런싱한다.
