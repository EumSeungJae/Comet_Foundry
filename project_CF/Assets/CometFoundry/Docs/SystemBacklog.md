# Comet Foundry System Backlog v0.1

## 1차 골격

현재 골격은 구현 우선순위를 다음처럼 둔다.

1. 회사 상태
2. 혜성 상태
3. 자원과 재고
4. 시설과 생산 레시피
5. 운송 노선과 자동화 규칙
6. 시장 판매
7. 연구 해금

이 순서가 중요한 이유는 플레이어가 직접 운영하는 대상이 회사이기 때문이다. 혜성, 공장, 운송선은 모두 회사 자산으로 연결된다.

## 핵심 시스템 책임

### 혜성 생성

`CometGenerationProfile`과 `CometGenerator`가 담당한다.

- 크기
- 위치
- 자원 종류
- 자원 매장량
- 빈 혜성 가능성

초기에는 단순 확률 생성으로 시작하고, 이후에는 구역, 희귀도, 탐사 장비 보정치를 추가한다.

### 자원 시스템

`ResourceDefinition`, `ResourceDeposit`, `Inventory`가 담당한다.

- `ResourceDeposit`: 혜성 안에 묻힌 유한 자원
- `Inventory`: 시설이나 화물선에 들어 있는 이동 가능한 물자
- `ResourceDefinition`: 철광석, 철, 강철 같은 정적 데이터

자원 매장량은 고갈되지만 혜성은 사라지지 않는다.

### 공장 시스템

`FacilityDefinition`과 `FacilityInstance`가 담당한다.

- 광산
- 정제소
- 공장
- 조립공장
- 창고
- 물류허브
- 연구소
- 판매 터미널

시설은 혜성에 설치되는 인스턴스이며, 각 시설은 자체 재고를 가진다.

혜성 내부 배치는 XCOM 방식의 사각 타일 보드로 다룬다. 시설은 `FacilityDefinition.FootprintSize`만큼 타일을 점유한다.

### 혜성 내부 타일 배치

`CometGrid`, `CometTile`, `PlacementSystem`, `RailSegment`가 담당한다.

- 각 혜성은 자체 사각형 배치도를 가진다.
- 타일은 안정 지형, 거친 지형, 균열 지형, 공백 지형으로 나뉜다.
- 건물과 레일은 같은 타일을 동시에 점유할 수 없다.
- 초기 레일은 단일 타일 세그먼트로 시작한다.
- 이후 레일 방향, 교차, 입출구, 처리량, 병목 규칙을 추가한다.

테스트 씬:

- `Assets/CometFoundry/Scenes/ConstructionTestScene.unity`
- 좌클릭으로 현재 모드의 배치물을 놓는다.
- `Tab`으로 2x2 테스트 구조물과 레일 배치 모드를 전환한다.
- 레일 모드에서는 마우스가 지나간 인접 타일 경로를 미리보고, `Enter` 또는 HUD 버튼으로 확정한다.
- 마우스가 비인접 타일로 건너뛰면 자동 경로를 만들지 않고 연결하지 않는다.
- `Esc` 또는 HUD 버튼으로 레일 프리뷰를 취소한다.
- 확정된 레일 라인에는 방향 검증용 구체가 생성되어 드래그한 순서대로 이동한다.
- 한 레일 라인의 끝이 다른 레일 라인의 시작점과 맞닿아 있으면 테스트 구체가 다음 라인으로 전달된다.
- 레일 라인의 끝이 건물 타일과 맞닿아 있으면 테스트 구체가 건물로 입고된다.
- 테스트 건물은 입고 3개 미만이면 빨간색, 3개 이상이면 파란색으로 표시된다.
- 파란색 건물의 하단 라인에 컨베이어 시작점이 있으면 생산 구체를 해당 컨베이어에 배출한다.
- 생산 출구는 임시로 건물 발자국의 맨 아래쪽 라인만 사용한다.
- 생산 시 건물 내부 스택 3개를 소비한다.
- 건물 내부 스택이 3개 이상이면 추가 입력 구체는 컨베이어 끝에서 대기한다.
- 건물 하단 출구와 연결된 컨베이어 시작점에는 자연 테스트 구체를 만들지 않는다.
- `R`로 보드를 초기화한다.

### 생산 라인

`RecipeDefinition`과 `FacilityInstance.TickProduction`이 담당한다.

초기 모델은 하나의 시설이 하나의 활성 레시피를 실행한다. 이후 생산 라인 슬롯, 전력, 인력, 유지보수, 효율 보너스를 추가할 수 있다.

### 물류 시스템

`TransportRoute`, `AutomationRule`, `CargoShipState`, `LogisticsSystem`이 담당한다.

운송은 플레이어가 직접 반복 조작하는 일이 아니라, 조건과 우선순위에 따라 자동화되어야 한다.

초기 자동화 규칙:

- 특정 자원이 일정 톤 이상 쌓이면 출발
- 도착지에 여유 용량이 있으면 운송
- 우선순위가 높은 노선을 먼저 선택

### 연구 시스템

`ResearchDefinition`과 `ResearchSystem`이 담당한다.

연구는 새 시설, 새 운송선, 효율 개선, 탐사 능력, 자동화 규칙 확장을 여는 역할로 둔다.

### 시장 경제

`MarketSystem`이 담당한다.

현재는 기본 가격과 배율만 둔다. 이후 수요, 공급 과잉, 계약, 시장 허브 거리 보정, 운송 비용을 연결한다.
