# 거래소·혜성관리 플레이어 안내 (2026-10-08)

이 문서가 최신 플레이 구성입니다. 이전 플레이어블 문서의 시작 생산시설과 5등급 자동판매 설명은 초기 버전에 해당합니다.

## 실행

`Builds/CometFoundry/CometFoundry.exe` 실행. exe와 같은 폴더의 Data, DLL 파일을 함께 유지하세요. Unity에서는 `Assets/CometFoundry/Scenes/FoundryPlayableScene.unity`를 열고 Play를 누르세요.

## 시작과 튜토리얼

기본 시설은 발전소, 창고, 철광석·구리광석 채굴기 2개입니다. 기본 창고의 지원 드론이 재고와 생산 재료를 자동 운반합니다. 건물 사이 빈 통로를 남기세요.

우측 안내를 따라 정제소 건설 → 철 제련 설정 → 철 2스택 생산 → 금속 가공소 건설 → 철판 압연 설정 → 철판 2스택 생산 → 거래소 건설 → 판매 → 구매 순서로 진행합니다. 추천 좌표는 정제소 (5,3), 금속 가공소 (8,3), 거래소 (12,7)입니다. 생산 건물 클릭 팝업에서 투입 소재, 생산 비용, 소요 시간, 완성품을 확인하고 생산품을 설정합니다. 건너뛰기와 안내 다시 보기도 지원합니다.

## 거래소

거래소 건설 시 HUD 우측 하단의 거래소·혜성관리 버튼이 활성화됩니다. 거래소 건물을 클릭해도 거래 화면이 열립니다. 보유 혜성 중 한 곳에 거래소가 있으면 다른 개척지에서도 이용할 수 있습니다.

좌측 목록은 모든 소재와 현재 혜성/회사 전체 재고를 표시합니다. 5등급 제한 없이 모든 등급을 사고팔 수 있습니다. 중앙 기준 시세 그래프는 기본 6개월이며 6/12/18/24개월을 선택합니다. 그래프에 마우스를 올려 해당 시점 금액을 확인합니다. 우측에서 실제 개당 판매가·구입가 확인 → 구입/판매 선택 → 정수 수량 드래그 → 거래 확인 순서로 거래합니다. 여기서 1개는 게임 재고 단위인 1스택입니다.

구매는 현재 선택 혜성의 창고·항구·거래소 공간에 입고됩니다. 판매는 현재 혜성 전체 시설의 해당 소재 재고에서 차감합니다. 자금·재고·공간이 부족하면 거래가 차단됩니다. 초기 시장 매입/매출 가격 차이는 기존 시장 규칙을 따릅니다. 자동판매는 새 게임에서 꺼져 있습니다.

## 탐사와 개척

혜성관리 좌측에서 소유 혜성의 이름, 좌표, 남은 광맥 자원, 누적 판매 수익을 확인하고 선택해 개발 구역을 전환합니다. 판매 수익은 비용을 공제하기 전 누적 판매금입니다. 선택하지 않은 혜성도 생산을 계속합니다.

우측 탐사는 1,500솔라/8초입니다. 기존 등급·크기·시드·거리 생성 규칙에 따라 후보 3개를 발견합니다. 후보 하나를 선택하고 개척 비용을 지불하면 해당 혜성에 소형 항구가 건설되고 소유 목록에 추가됩니다. 개척 비용은 8,000 + 타일 수×45 + 거리 분×5 + 항구 비용 5,000솔라입니다. 이후 좌측 새 혜성을 선택해 발전소, 채굴기, 생산시설 등을 건설합니다.

좌측 하단 경영지표는 실제 월별 회사 보유금액 기록입니다. 시작 전 가상의 회사 잔액은 생성하지 않으므로 처음에는 점 하나만 표시되고 월이 지나면 선 그래프가 됩니다. 시장 시세 그래프의 과거 기록은 회사 설립 전에도 존재하는 시장 기록입니다. 게임 하루=기본속도 300초, 한 달=30일입니다.

## 수송선

첫 수송선은 무료로 제공되며 용량은 100스택입니다. 추가 구매는 12,000솔라입니다. 수송선 관리에서 대기 선박, 출발 혜성, 도착 혜성, 물자, 수량을 선택하고 운송 시작을 누릅니다. 두 혜성을 소유해야 하며 출발/도착이 달라야 합니다. 시작 혜성 창고는 임시 선착장 역할을 하고 개척지는 항구를 사용합니다.

운송비=25 + 수량×0.5 + 운송시간×2솔라. 운송시간=8 + 두 혜성 거리 분 차이×0.025초입니다. 출발 재고는 즉시 선박 화물로 옮기며 도착 시 항구에 하역합니다. 항구가 차면 남은 화물을 선내에 보관하고 공간이 생길 때까지 기다립니다. 거래소 판매 등으로 공간을 확보할 수 있습니다.

## 저장과 검증

상단 저장/불러오기는 모든 혜성, 광맥 잔량, 건물·레시피·생산 진행, 재고, 자금, 탐사 후보/진행, 수송 중 화물/진행, 월 잔액, 튜토리얼을 보존합니다. 기존 v1 저장은 단일 혜성 데이터로 가져옵니다. 잘못된 v2 데이터는 현재 플레이를 변경하지 않고 거부합니다.

Unity EditMode 테스트 18개 통과: 생산 비용/재료 보존, 산업장비 전체 생산라인, 모든 등급 거래, 6/12/18/24개월 시세, 후보 3개와 항구 포함 개척, 수송 중 저장·복원, 만원 항구 대기/부분 하역, 비선택 혜성 생산, 실제 튜토리얼 완료. Windows 개발 빌드를 생성했습니다. 자동 캡처 환경에서 화면 렌더링을 확인할 수 없어 최종 화면의 시각적 검수는 완료하지 못했습니다.
