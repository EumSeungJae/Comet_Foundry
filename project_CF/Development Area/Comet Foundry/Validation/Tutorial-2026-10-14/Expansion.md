# 혜성 구매·이동·운송 튜토리얼 확장

작업일: 2026-10-14

기존 안내에 12번 혜성 구매, 13번 혜성 간 이동, 14번 물자 이동 실습을 추가했다. 총 14개 주제, 82개 세부 단계다. 노란 타깃 박스와 개별 지시 팝업을 유지한다.

- 혜성 구매: 탐사 시작 → 완료 대기 → 후보 비교·선택 → 개척비 지불 → 보유 혜성 증가 확인.
- 혜성 간 이동: 구매한 혜성 슬롯 선택 → 개발 보드 확인 → 출발 혜성 복귀. 화면 전환과 화물 운송의 차이를 설명한다.
- 물자 이동: 출발 혜성에서 물 3스택 확보 → 수송선 관리 → 출발·도착 혜성 선택 → 물과 수량 선택 → 출항 → 실제 하역 완료 → 도착 혜성의 항구 재고 확인.

건설 메뉴 선택·시설 배치·건물 열기는 튜토리얼 확인 버튼 없이 즉시 조작할 수 있다. 선택한 시설을 배치 단계에서도 유지한다. 실제 건설 성공을 감지하면 다음 단계로 자동 진행하며, 실패한 건설은 단계를 진행시키지 않는다. 새 구매·이동·운송 실습도 확인 버튼 없이 행동 조건으로 자동 진행한다. 설명 전용 단계는 읽은 뒤 다음 버튼을 누른다.

## 검증

- Unity EditMode 36개 테스트 통과, 실패 0개. `GuidedTutorial-expansion-tests.xml` 참조.
- 전체 14개 주제를 끝까지 진행하며 실제 혜성 구매, 보유 혜성 전환, 물 3스택 운송과 도착 항구 입고를 검증했다.
- 건설 전후 안내 확인 없이 진행하고, 건설 실패 시 같은 단계에 머무르는 것을 검증했다.
- 출항만으로 운송 완료를 인정하지 않으며, 항구가 가득 찬 상태에서 도착하더라도 실제 하역 전에는 다음 단계로 넘어가지 않는 것을 검증했다.
- 기존 생산·드론·거래·미션·철거·저장 관련 테스트를 함께 실행했다.
- Windows 플레이 빌드 갱신 성공: `Builds/CometFoundry/CometFoundry.exe`. 빌드 로그: `GuidedTutorial-expansion-build.log`.
- 갱신된 실행 파일의 튜토리얼 화면 순회가 런타임 예외 없이 정상 종료했다. 실행 로그: `GuidedTutorial-expansion-player.log`.
- 숨김 실행 캡처는 이전과 같은 검은 단색 화면이므로 시각 검수 증거로 사용하지 않았다. 글자 크기와 팝업·타깃 비중첩은 테스트로 검증했으며, 실제 표시 화면의 최종 시각 검수는 미완료다.

현재 프로젝트가 Unity 에디터에 열려 있어 프로젝트 내부의 분리된 사본에서 검증했다. 검증 사본의 구현 및 테스트 파일이 원본과 동일한지 해시로 확인했다. 기존 열린 에디터를 닫지 않았다.

사용 안내: `Assets/CometFoundry/Docs/PlayableGuide.md`.
