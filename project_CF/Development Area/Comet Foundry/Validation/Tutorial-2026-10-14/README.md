# 순차 튜토리얼 구현 및 검증

작업일: 2026-10-14

후속 확장: [혜성 구매·이동·물자 운송과 건설 자동 진행](Expansion.md). 현재 안내는 14개 주제, 82개 세부 단계이며, 아래는 최초 11개 주제 구현 시점의 기록이다.

최신 수정: [실제 건설 완료 검사와 행동 단계 확인 버튼 제거](AutoConstruction.md).

기존 19개 설명 페이지를 11개 주제, 65개 세부 단계의 순차 안내로 교체했다. 각 단계는 별도 지시 팝업과 노란 타깃 박스를 사용한다. 팝업은 타깃과 겹치지 않게 배치하며, 중앙 차트 옆에서는 좁은 팝업을 사용한다. 생산 설정 안내는 왼쪽에 배치해 오른쪽 재료·비용 정보를 보존한다.

설명 확인 전에는 시간과 배경 조작을 멈춘다. 확인 후 실제 건설·생산·거래·미션 UI를 조작하며 목표 완료 시 다음 팝업을 표시한다. 기존 시설 사용과 시설 철거·미션 취소 후 단계 복구를 지원한다.

## 주제 순서

1. 채굴기 건설과 원자재 생산.
2. 정제소 건설과 철괴 1차 생산.
3. 금속 가공소 건설과 철판 2차 생산.
4. 구리괴 공급, 전자 가공소 건설, 구리선과 회로기판 3차 생산, 조립 재료 공급을 위한 구리선 생산 재개.
5. 일반 조립소 건설과 전자부품 4차 생산.
6. 창고와 항구의 기능.
7. 드론 격납고와 발전소의 역할.
8. 거래소 터미널 건설.
9. 보유 소재, 시세 차트, 구매·판매 실습.
10. 미션 수주, 재고 확보, 납품과 보상.
11. 보유 혜성, 개인자금 변동지표, 탐사·개척, 수송선 관리.

생산 실습은 해당 시설의 실제 생산량으로 판정하며 구매 재고는 생산 완료로 인정하지 않는다. 구리선 9스택과 회로기판 2스택을 확보하고 조립소 공급을 위해 구리선 생산을 재개한다. 회로기판 생산 중 입력 재료가 예약되어 조립소 공급이 막히는 상황을 드론 테스트로 재현해 안내 순서를 보완했다.

## 검증 결과

- Unity 6000.3.19f1 EditMode: 최종 35개 통과, 실패 0개. GuidedTutorial-final-tests.xml 참조.
- 신규 3개 테스트: 전체 11개 주제 진행, 팝업/타깃 비중첩·화면 범위·안내문 크기, 생산 완료 판정·구매 오인 방지, 실제 드론 물류만으로 전체 생산 사슬 수행.
- 기존 생산·관리·시세·철거·미션·저장 관련 테스트 32개 통과.
- Windows 빌드 성공: Builds/CometFoundry/CometFoundry.exe. GuidedTutorial-build.log 참조.
- 숨김 및 그래픽 배치 실행 모두 정상 종료. 런타임 예외 로그 없음. GuidedTutorial-player.log, GuidedTutorial-offscreen.log 참조.
- 자동 화면 캡처는 검은 단색 화면이라 시각 검수 증거로 사용할 수 없다. 실제 실행 창에서 팝업·노란 박스·글자 표시를 확인하는 최종 시각 검수는 미완료다.

이전 프로젝트 경로 D:/Programming/project_CF를 참조하던 Unity Bee 캐시로 첫 검증이 중단됐다. 기존 캐시를 Library/Bee.BeforeGuidedTutorial에 백업하고 현재 경로에서 재생성한 뒤 검증과 빌드에 성공했다.

## 실행과 저장

Windows 실행 파일 또는 FoundryPlayableScene의 Play에서 새 개척 → 튜토리얼 시작을 선택한다. 상단 튜토리얼 버튼으로 다시 시작할 수 있다. 안내 종료는 현재 시설·자금·수주 미션을 유지한다.

개척과 미션은 기존 저장 기능을 사용한다. 신규 안내의 세부 팝업 위치는 저장하지 않으며, 불러온 게임에서 안내를 시작하면 첫 주제부터 기존 시설을 활용한다.
