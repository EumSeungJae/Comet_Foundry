# 소형 4대·중형 8대 드론 운용

소형 드론 저장소(`drone-storage`, 1x2)는 4대, 중형 드론 격납고(`drone-hangar`, 2x2)는 8대다. 기존 시설 종류와 건설 크기는 유지하고 시설 정의의 드론 수를 실제 병렬 작업 슬롯과 전체 보유 수에 적용했다. 소형 1개와 중형 1개를 함께 운용하면 총 12대다.

전력은 드론 4대당 1로 소형 1, 중형 2를 사용한다. 시설 정보창은 실제 시설의 보유 수를 표시한다. 드론 번호는 앞 시설들의 보유 수를 누적해 중복되지 않으며 중형의 8개 슬롯도 화면에서 분리한다. 튜토리얼과 플레이 가이드도 갱신했다. 생산 건물 입출고 대기열 합계 2개 제한은 유지한다.

## 자동 검사

Unity 6000.3.19f1 별도 프로젝트에서 전체 110개 중 105개 통과. 새 실패는 없다. 소형 단독 4대, 소형+중형 총 12대 동시 배정과 시설별 실제 작업 수, 20초 동안 생산 건물 대기열 최대 2개, 배송량 증가, 철거 취소와 전력 부족 정지, 재고 예약·저장 복원을 검사한다.

기존 실패 5개는 그대로다. 미사용 시장·의뢰 4개는 차후 개선 항목이며, 나머지 시드 테스트는 NUnit 문자 범위 검사에서 발생하는 것으로 분석되어 있다. 이번 요청에서는 그 코드를 변경하지 않았다.

기존 저장도 불러올 때 최신 시설 정의를 사용하므로 소형 4대·중형 8대가 적용된다. 사용자 저장을 덮어쓰거나 임의로 시설을 추가하지 않았다.

최종 병렬 검사 6개 모두 통과했으며 저장 복원 후에도 총 12대를 확인했다. 원본·검증 사본 C# 76개 파일 해시가 일치했다. Windows 빌드 성공 후 실제 1280×800 창에서 지원시설 0개/소형 1개/소형+중형 각각 12장, 총 36장을 촬영했다. [측정값](screenshots/metrics.tsv)에서 소형+중형 12대 동시 작업과 생산 대기열 최대 2개를 확인했다. 이후 수요를 채우면 일부 드론이 정상적으로 대기한다. 플레이어 예외는 없었다.
