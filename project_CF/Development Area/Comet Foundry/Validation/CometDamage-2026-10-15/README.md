# 혜성 손상 분포 재조정 검증

Unity 6000.3.19f1 별도 프로젝트에서 전체 110개 중 105개 통과. 기존 실패 5개만 유지되고 새 실패는 없다. 해당 5개는 이미 분석한 NUnit 문자 범위 검사 1개와 차후 개선 대상으로 분류한 시장·의뢰 4개다.

원본과 검증 사본 C# 76개 파일 해시가 일치한다. 사용자 저장 데이터는 변경하지 않았다.

## 지형 검사

7개 등급 × 8개 크기(9~16) × 16개 시드 = 896개 조합에서 다음 항목을 전부 통과했다.

- 등급별 목표 활성 타일 수와 실제 수량 일치.
- 내부 손상 수가 전체 손상 수의 약 20%에 해당하는 반올림 수량과 일치(S 제외 최소 1개).
- 외곽 손상 수가 내부 손상 수보다 많음.
- 내부 구멍이 상하좌우·대각선으로 다른 손상 타일과 붙지 않음.
- 중앙의 가로·세로 통로가 온전히 보존됨.
- 모든 활성 타일이 상하좌우 경로로 연결됨.

전체 튜토리얼과 병렬 드론·생산·저장 관련 테스트도 통과했다.

| 등급 | 이전 손상률 | 신규 손상률 |
|---|---:|---:|
| S | 0% | 0% |
| A | 2% | 4% |
| B | 4% | 7% |
| C | 6% | 10% |
| D | 8% | 13% |
| E | 10% | 16% |
| F | 12% | 20% |

타일 단위 반올림으로 실제 비율은 소폭 달라질 수 있다. 손상의 약 80%는 외곽 한 줄, 약 20%는 내부이며 중앙 통로와 연결성을 우선한다. 기존 저장 지형은 유지하고 신규 생성 혜성에 적용한다. 이후 건물 배치로 통로를 막으면 드론 운송이 중단될 수 있으므로 건설 시 통로를 남겨야 한다.

## 실행 확인

Windows 빌드 성공 후 실제 1280×720 창에서 66개 화면을 촬영했다. 새로 생성·개척한 혜성의 화면에서 외곽 손상과 작은 내부 구멍이 함께 나타남을 확인했다. 화면 배치 검사 전부 통과, 텍스트 넘침 경고 0개, 플레이어 예외 0개다. 실행 파일은 `Builds/CometFoundry/CometFoundry.exe`에 갱신했다.
