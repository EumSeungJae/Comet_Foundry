# 일반 미션 15개 개편 검증

작업일: 2026-10-14

튜토리얼 미션 1개를 유지하고 일반 미션 15개를 새 식별자로 구성했다. 2차·3차·4차 가공별 5개이며, 일반 미션은 소재 2~5종을 요구한다. 미션 등급은 가장 높은 요구 소재 등급으로 정하고 원자재·1차 소재 및 5등급 완제품은 신규 일반 미션에서 제외했다.

전체 요구량과 보상 표: ../../Planning/MissionCatalog-2026-10-14.md.

## 핵심 보상

- 10번: 프레임 24, 기어 24, 회로기판 30, 철판 40, 구리선 40스택 → 29,600솔라와 항구 포함 혜성 1개.
- 11번: 기계부품 12, 전자부품 10, 프레임 16스택 → 28,100솔라와 적재 한도 100스택 수송선 1척.
- 15번 우주선 부품납품: 기계부품 40, 전자부품 40, 프레임 60, 기어 80, 회로기판 60스택. 총 280스택 → 197,300솔라.

현금 보상은 소재 정가 합계의 2차 1.35배, 3차 1.55배, 4차 1.80배를 100솔라 단위로 올림했다. 자산 보상이 있는 10번은 1.05배, 11번은 1.30배로 현금을 조정했다. 가격 변동과 초기 구매 배율 1.75배를 고려해 생산 납품 중심으로 설계했으며 모든 시장 상황에서 구매 납품 수익을 보장하는 구조는 아니다.

## 기능

HUD와 미션 목록에 모든 요구 소재의 진행도와 현금·혜성·수송선 보상을 표시한다. 소재 하나라도 부족하면 어떠한 납품 재고도 차감하지 않는다. 보상 지급 가능 여부도 재고 차감 전에 확인한다. 완료 이후 재수주 또는 저장 불러오기로 보상을 재지급하지 않는다.

보상 혜성은 10×10, 항구 1개, 철광석·구리광석·얼음 각 4,000스택 매장 자원을 제공한다. 보유 혜성 및 탐사 후보와 좌표가 중복되지 않으며 자원 시드와 이동 거리를 기존 좌표 규칙에 맞췄다. 탐사 후보와 진행 중인 탐사는 변경하지 않는다.

저장 형식 4번으로 갱신하고 기존 2·3번 저장을 지원한다. 옛 단일 소재 미션의 진행 계약은 당시 요구량과 보상으로 유지한다. 은퇴한 미션의 완료 기록도 보존하고, 신규 일반 미션은 별도 식별자로 제공한다. 튜토리얼 미션은 기존 식별자를 유지한다.

## 검증 결과

- Unity 6000.3.19f1 EditMode: 43개 통과, 실패 0개. MissionCatalog-tests.xml 참조.
- 신규 7개 테스트: 미션 개수·등급·소재 종류·보상 계산, 부족 소재가 있는 납품의 원자성, 혜성 지급·좌표·시드·거리·탐사 보존·저장, 수송선 지급·저장·중복 방지, 최종 5종 납품, 옛 계약 저장 호환, 수송선 보유 한도에서의 재고 보존.
- 기존 튜토리얼·생산·물류·시세·미션·철거·저장 테스트 36개도 함께 통과.
- Windows 빌드 갱신 성공: Builds/CometFoundry/CometFoundry.exe. MissionCatalog-build.log 참조.
- 새 미션 목록과 진행 화면의 숨김 실행 점검이 런타임 예외 없이 정상 종료했다. MissionCatalog-player.log 참조.
- 숨김 실행 캡처는 검은 단색 화면이어서 시각 검수 증거로 사용하지 않았다. 실제 표시 화면의 최종 시각 검수는 미완료다.

열린 Unity 에디터를 유지하기 위해 프로젝트 내부의 분리된 사본에서 검증·빌드했고, 원본과 검증 소스의 해시 일치를 확인했다.
