# 드론 병렬 물류 검증

검증일: 2026-10-14. Unity 6000.3.19f1, 별도 검증 프로젝트에서 실행. 원본 프로젝트의 C# 76개 파일과 검증 사본의 해시가 모두 일치했다. 사용자 저장 데이터를 사용하거나 덮어쓰지 않았다.

## 자동 테스트

103개 중 98개 통과. 신규 `FoundryParallelDroneTests` 6개 모두 통과:

- 지원시설 1개/2개에서 4대/8대 실제 배정 및 20초 동안 생산 대기열 최대 2개 유지.
- 같은 수요에서 격납고 추가 후 누적 배송량 증가.
- 창고만 남아 있으면 운송 중지, 지원시설 철거 시 진행 작업 취소.
- 전력 부족 시 동시 작업 전체 진행 정지.
- 출발 재고와 목적지 공간 예약 한도, 운송 도중 저장·복원 시 120스택 보존.

기존 중복 채굴기·정제소·가공소의 희소 공급 공정성 테스트, 튜토리얼, 전체 생산 흐름도 통과했다.

수정 전부터 존재했던 실패 5개는 그대로다: 생성기 시드 범위 예외, 시장 이벤트 부동소수점 오차, 시장 신뢰도 0/3 가격 기대값 두 항목, 의뢰 갱신 ID 기대값. 이번 변경에 따른 신규 실패는 없다.

## 저장 호환과 플레이 조건

새 게임은 기존 발전소·창고·채굴기 2개에 드론 저장소 1개가 추가된다. 기존 저장의 시설은 임의로 바꾸지 않는다. 저장소/격납고가 없다면 새로 건설해야 내부 운송이 시작된다. 광물 채굴 자체는 내부 운송과 별개이므로 지원시설 없이도 채굴기 내부 재고가 찰 수 있다.

지원시설에서 출발지·목적지까지 빈 통로가 이어져야 한다. 공급 재고, 목적지 공간, 전력이 필요하며 실제 운송 수요가 부족하면 일부 드론은 정상적으로 대기한다. 진행 중 작업은 저장 후 다시 배정되지만 재료는 원본 재고에 보존된다.
