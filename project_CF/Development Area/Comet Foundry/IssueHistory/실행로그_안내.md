# 실행 로그 읽는 법

한글 안내 작성일: 2026-10-14

이 폴더의 실행 로그는 당시 Unity 엔진이 출력한 원문이다. 오류 문구, 경로, 수치, 호출 정보를 정확히 검색할 수 있도록 로그 파일은 수정하지 않았다.

## 로그별 용도

- [일반 실행 로그](GameplayRevision-player.log): 게임 실행과 엔진 초기화 과정 등을 기록한다.
- [오프스크린 실행 로그](GameplayRevision-player-offscreen.log): 화면 밖에서 진행한 실행 기록이다.
- [최종 실행 로그](GameplayRevision-player-final.log): 최종 실행 과정의 기록이다.

## 주요 문구의 한글 뜻

| 원문 문구 | 한글 설명 |
| --- | --- |
| Mono path / Mono config path | 관리 코드 실행 파일 및 Mono 설정의 위치 |
| Player connection | 실행 중인 게임과 개발 도구의 연결 정보 |
| Input System module state changed to: Initialized | 입력 시스템 초기화 완료 |
| Initialize engine version | 실행에 사용한 Unity 엔진 버전 |
| Discovering subsystems | 엔진 하위 시스템을 찾는 과정 |
| Forcing GfxDevice: Direct3D 11 | 그래픽 장치를 Direct3D 11 방식으로 지정 |
| Renderer / Vendor / VRAM / Driver | 그래픽 장치 이름 / 제조사 / 그래픽 메모리 / 드라이버 |
| Begin MonoManager ReloadAssembly | 관리 코드 어셈블리 다시 불러오기 시작 |
| Loaded All Assemblies | 어셈블리 불러오기 완료 |
| Symbol file LoadedFromMemory is not a mono symbol file | 메모리에서 읽은 디버깅 기호 파일이 Mono 기호 파일 형식과 다르다는 메시지 |
| d3d12: failed to query info queue interface | Direct3D 12 그래픽 진단 인터페이스 조회 실패 |
| Curl error 7: Failed to connect | 지정된 서버에 연결하지 못한 네트워크 오류 |
| UnloadTime | 불필요한 자산 등을 해제하는 데 걸린 시간 |
| Cleanup current backend / PlayerConnection::Cleanup | 물리 엔진 또는 개발 도구 연결의 종료 정리 |
| MemoryLeaks / allocatedMemory / memoryLabels | 종료 시점의 메모리 진단 항목과 할당량·분류 정보 |

## 기록에서 확인할 수 있는 사항

오프스크린 및 최종 실행 로그에는 Unity 관련 서버의 443번 포트에 연결하지 못한 기록이 있다. 일반 실행 로그에는 Direct3D 12 진단 인터페이스 조회 실패 메시지가 있다. 이 메시지들은 해당 시점에 관측된 기록이며 현재 발생 여부나 게임 기능에 미친 영향은 별도 확인이 필요하다.

[게임플레이 수정 검증 문서](GameplayRevision-review.md)에는 숨김 실행이 정상 종료했으나 자동 캡처가 빈 화면이어서 팝업 시각 검수가 미완료였다고 기록되어 있다. 엔진 초기화나 종료 기록만으로 실제 화면 배치 검수가 완료된 것으로 판단하지 않는다.
