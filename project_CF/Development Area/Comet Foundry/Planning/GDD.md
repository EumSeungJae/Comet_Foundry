# Comet Foundry GDD

## 1. Game Overview

### Title

Comet Foundry

### Genre

2D 산업 경영 및 물류 시뮬레이션

### Core Fantasy

플레이어는 하나의 광산이나 공장이 아니라, 여러 혜성 자산을 운영하는 기업을 경영한다. 혜성을 발견하고, 채굴하고, 산업 시설을 구축하고, 물류망을 연결해 우주 산업망을 성장시킨다.

### Core Question

회사는 보유한 혜성 자산을 얼마나 효율적으로 활용하고 있는가?

## 2. Core Pillars

### Factory Design

자원을 채굴하고, 제련·가공·조립을 거쳐 완제품을 만드는 생산 라인을 설계하는 재미이다.

### Industrial Network

여러 혜성을 채굴장, 제련소, 공장, 물류 거점으로 특화하고 화물선과 수송 루트를 최적화하여 하나의 산업 네트워크를 구축하는 재미이다.

### Company Management

계약을 수행하고 시장에 제품을 공급하면서 새로운 혜성을 확보하고 생산 규모를 확장하는 성장의 재미이다.

## 3. World Design

### Comets

혜성은 회사가 발견하고 확보하는 핵심 자산이다. 각 혜성은 내부 개발 보드, 자원 매장량, 위치, 산업 용도를 가진다.

### Comet Generation

- 혜성 생성
- 자원 분포
- 자원 매장량
- 빈 혜성 가능성
- 혜성 위치와 크기

### Comet Grade And Seed

혜성은 8자리 시드코드를 가진다. 각 자리는 혜성의 핵심 생성 규칙을 의미한다.

| 자리 | 의미 |
| --- | --- |
| 1 | 건설 가능 타일 활성화 비율 코드 |
| 2 | 혜성 내부 보드 크기 코드 |
| 3 | 랜덤 생성되는 자원 종류 수, 0~3 |
| 4~6 | 혜성에 부여되는 자원 종류 코드 |
| 7 | A-0 관문 기준 거리 알파벳 코드 |
| 8 | A-0 관문 기준 거리 숫자 코드 |

1번째 자리와 2번째 자리는 `A`, `B`, `C`, `D`, `E`, `F`, `S` 중 하나를 사용한다.

활성화 비율 코드:

| 코드 | 건설 가능 타일 활성화 |
| --- | ---: |
| S | 100% |
| A | 96% |
| B | 93% |
| C | 90% |
| D | 87% |
| E | 84% |
| F | 80% |

2026-10-15 조정: 손상 타일은 약 80%를 외곽 한 줄, 약 20%를 내부에 배치한다. 내부 손상은 최소 1개(무손상 S 제외)이며 타일 단위 반올림을 적용한다. 내부 구멍끼리 대각선을 포함해 인접하지 않게 하고, 외곽과 내부 구멍 사이에는 한 줄의 타일을 남긴다. 중앙 가로·세로 통로를 보존하며 모든 활성 타일이 상하좌우로 연결되어야 한다. 기존 저장된 혜성 지형은 유지한다. 건설 시에도 건물 사이에 최소 폭 1칸의 빈 통로를 남겨야 한다.

사이즈 코드:

| 코드 | 내부 보드 크기 |
| --- | ---: |
| S | 16 x 16 |
| A | 14 x 14 |
| B | 13 x 13 |
| C | 12 x 12 |
| D | 11 x 11 |
| E | 10 x 10 |
| F | 9 x 9 |

7~8번째 자리는 혜성 간 거리 차이를 크게 다루기 위한 거리 코드이다. `A0`은 A-0 관문 좌표로 예약하므로 혜성에는 사용하지 않는다. 혜성은 `A1`부터 `Z9`까지의 값을 사용한다.

- 숫자 코드 1 차이: 5분 거리
- 알파벳 코드 1 차이: 1시간 거리
- 새 혜성의 거리 코드가 이미 소유한 혜성과 같으면 다시 산출해 다른 거리 코드를 부여한다.

### Resource Depletion

자원 매장량은 유한하다. 채굴이 끝난 혜성은 사라지지 않고 공장 부지, 물류 허브, 연구 거점, 정거장 등으로 계속 활용될 수 있다.

### Industrial Districts

혜성 내부는 XCOM 방식의 사각 타일 보드로 다룬다. 건물과 컨베이어는 이 보드 위에 배치되며, 혜성의 역할에 따라 채굴 구역, 제련 구역, 조립 구역, 창고 구역, 항구 구역으로 특화될 수 있다.

## 5. Logistics Design

두 번째 핵심 영역이다. 물류는 반복 수동 조작이 아니라 조건, 우선순위, 노선 설계로 자동화되는 방향을 따른다.

### Logistics Tools

- 컨베이어
- 파이프
- 화물 드론
- 화물선
- 수송선
- 자동 물류

### Route Philosophy

플레이어는 물자를 직접 계속 옮기기보다, 어떤 물자가 어디에 얼마나 쌓였을 때 어디로 보내야 하는지를 설계한다.

### Early Rules

- 특정 자원이 일정량 이상 쌓이면 출발
- 도착지에 여유 용량이 있으면 운송
- 우선순위가 높은 노선을 먼저 선택

## 6. Economy Design

경제는 생산물의 목적지를 만든다. 플레이어는 생산 체인을 통해 계약을 수행하고, 시장에 물자를 판매하며, 기업을 성장시킨다.

### Economy Elements

- 판매
- 계약
- 수익
- 시장가격
- 유지비
- 기업 성장

### Market Direction

초기에는 기본 가격과 판매 처리를 먼저 둔다. 이후 수요, 공급 과잉, 계약 조건, 시장 허브 거리 보정, 운송 비용을 연결한다.

### Comet Exchange

Comet Foundry의 회사는 `A0` 좌표의 A-0 관문과 연결되어 있다. A-0 관문은 모든 혜성 좌표와 지구권 거래의 기준점이다.

A-0 관문에는 혜성거래소가 기능한다. 혜성거래소는 지구로 물건을 보내 판매하는 거래 회사이며, 플레이어 대신 혜성을 찾고 소개해주며, 납품받은 제품을 지구 시장에 판매한다.

혜성거래소는 다음 역할을 가진다.

- 제품 판매 창구
- 계약 발주처
- 시장가격 기준점
- 지구 뉴스 전달자
- 초반 부족 재료 구매처
- 혜성 탐색과 소개

`A0`은 A-0 관문의 예약 좌표이며 일반 혜성 생성에는 사용하지 않는다.

### Construction Material Economy

건물을 지을 때는 돈만 쓰는 것이 아니라 가공품 재료와 완성품 재료가 필요하다.

예시:

- 채굴기: 철괴, 기계부품, 전자부품
- 용광로: 강철, 내열부품, 제어장치
- 창고: 구조재, 운송모듈, 전력부품
- 항구: 강철, 엔진, 항법장치, 대형 프레임

회사가 필요한 건설 재료를 직접 생산할 수 있으면 건설 비용이 크게 줄어든다. 자체수급이 완성된 회사는 해당 건물 건설 비용의 대부분을 물자 비용으로 대체할 수 있다.

초기 규칙:

- 외부 구매 의존: 정가 건설
- 일부 자체수급: 자체 생산한 재료만큼 비용 감소
- 전부 자체수급: 건설 비용 90% 절감
- 남은 10%는 행정비, 설치비, 인허가, 운송비, 인건비로 취급

이 규칙은 회사 성장의 보상을 만든다. 플레이어는 단순히 판매 수익을 올리는 것뿐 아니라, 생산망을 내재화해서 확장 비용을 낮출 수 있다.

### Market Price And Demand Events

지구에는 사건이 발생하고, 사건은 제품군의 수요와 시세를 바꾼다. 이 시스템은 플레이어가 어떤 회사 컨셉으로 성장할지 선택하게 만드는 핵심 경제 장치이다.

플레이어는 일정 확률로 혜성거래소에서 지구 뉴스와 소식을 받는다. 뉴스는 미래 이벤트의 확정 알림이 아니라 가능성 신호이다. 플레이어는 이 신호를 보고 생산 라인과 공장 투자를 미리 준비할 수 있다.

예시:

```text
뉴스: 전쟁 분위기가 감지된다.
선택: 플레이어가 군수품 공장과 포탄 생산 라인에 투자한다.
결과 A: 전쟁이 발발하면 군수품 가치와 계약 수요가 크게 증가한다.
결과 B: 평화롭게 끝나면 군수품 가치가 하락하고 투자 회수 기간이 길어진다.
```

이벤트 예시:

| 이벤트 | 주요 영향 |
| --- | --- |
| 인구 증가 | 가정용품, 가전제품, 생필품 수요 상승 |
| 전쟁 | 군용품, 포탄, 장갑재, 고성능 엔진 수요 급상승 |
| 전염병 | 의약품, 생필품, 정수 장비, 위생용품 수요 상승 |
| 우주개발 붐 | 우주선 부품, 항법장치, 엔진, 공업용품 수요 상승 |
| 에너지 위기 | 연료, 발전 설비, 우라늄, 에너지 저장장치 수요 상승 |
| 재건 사업 | 구조재, 건설부품, 공업용품 수요 상승 |

시장가격은 기본 가격에 수요 배율을 곱해 계산한다.

예시:

```text
판매가격 = 기본가격 x 시장 배율 x 계약 보정 x 거리/운송 보정
```

이벤트는 특정 제품군에 강한 기회를 만들지만, 플레이어가 해당 생산 체인을 준비하지 않았다면 바로 활용할 수 없다. 따라서 시장 이벤트는 장기 생산 전략과 회사 정체성을 흔드는 외부 압력으로 작동한다.

### Company Specialization

플레이어는 같은 원재료 풀을 가지고도 서로 다른 회사 컨셉을 만들 수 있다.

| 회사 방향 | 주요 제품 | 주요 고객/수요 |
| --- | --- | --- |
| 민간 생활 기업 | 가정용품, 가전제품, 생필품, 정수 장비 | 인구 증가, 전염병, 생활 인프라 |
| 상업 우주개발 기업 | 우주선 부품, 공업용품, 엔진, 항구 설비 | 우주개발 붐, 재건 사업 |
| 군수 기업 | 군용 포탄, 장갑재, 무기부품, 고출력 탄두 | 전쟁, 안보 위기 |
| 에너지 기업 | 연료, 발전 설비, 에너지 저장장치 | 에너지 위기, 대규모 산업 계약 |
| 연구/첨단 기업 | 고급 전자부품, 항법장치, 특수 소재 | 신기술 계약, 고급 우주개발 |

### Placement Rules

- 건물은 타일 발자국 크기를 가진다.
- 건물과 컨베이어는 같은 타일을 동시에 점유할 수 없다.
- 일부 건물은 입구와 출구 방향 규칙을 가진다.
- 건물은 설치, 회전, 철거, 충돌 검사를 지원해야 한다.
