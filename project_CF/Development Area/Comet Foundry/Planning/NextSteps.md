- 비활성 타일은 `Void` 지형으로 유지한다.

다음 작업 흐름은 시설 체계 확장이다.

1. 원재료 생산시설 제작
2. 원재료 가공시설 제작
3. 가공소재 부품화 및 완제품화 시설 제작
4. 창고시설 제작
5. 판매시설 제작

## 시설별 초기 역할

### 1. 원재료 생산시설

혜성의 자원 매장량에서 원재료를 생산하는 시설이다.

예상 예시:

- 철광석 채굴기
- 구리 채굴기
- 얼음 채취기
- 가스 포집기

초기 테스트에서는 자연 생산 구체의 출처를 이 시설로 대체한다.

### 2. 원재료 가공시설

원재료를 1차 가공품으로 바꾸는 시설이다.

예상 예시:

- 철광석 -> 철
- 구리광석 -> 구리
- 얼음 -> 물 / 연료 소재

현재 테스트 구조물의 “3개 입고 후 생산” 규칙을 이 단계에 먼저 적용한다.

### 3. 부품화 및 완제품화 시설

가공소재를 부품으로 만들고, 부품을 완제품으로 조립하는 시설이다.

예상 예시:

- 철 -> 강철
- 강철 -> 프레임
- 프레임 + 기계부품 -> 완제품

이 단계부터 복수 입력 조건을 고민한다.

### 4. 창고시설

컨베이어에서 들어온 물자를 저장하고, 필요할 때 다시 컨베이어로 내보내는 시설이다.

초기 목표:

- 입력 스택 보관
- 출력 컨베이어 연결
- 용량 제한
- 가득 찼을 때 컨베이어 대기

### 5. 판매시설

완제품을 받아 회사 자금으로 전환하는 시설이다.

초기 목표:

- 특정 구체를 판매 처리
- 판매 카운트 표시
- 이후 `MarketSystem` 재활성화 시 연결
