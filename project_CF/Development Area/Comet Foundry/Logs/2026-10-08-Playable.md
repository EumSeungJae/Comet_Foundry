# 2026-10-08 — 플레이 가능한 생산/경영 버전

사용자 요청: 세부 데이터는 구현자가 결정. 건물은 흰색 주색과 주황색 보조색. 생산 건물 클릭 시 생산품을 설정하는 팝업, 생산 코스트·소요시간·완성품 정보 필수.

`FoundryContent`에서 초기 자원·레시피·건설 데이터를 정의했다. `FoundrySession`에서 기존 시설 배치/인벤토리/전력/드론 경로와 우선도 시스템을 이용해 채굴→가공→조립→판매 루프를 연결했다. `FoundryPlayableController`와 별도 시작 장면을 추가했다. 기존 테스트 장면은 유지했다.

`FacilityInstance` 생산은 출력 전체를 보관할 공간과 재료·생산 비용이 충족될 때만 완성한다. 같은 레시피 재선택 시 진행도 보존, 다회 생산 시간 잔여분 보존, 저장 복원 진행도 처리를 추가했다. 생산 비용과 설명은 `RecipeDefinition`에 추가했으며 기존 데이터의 기본 비용은 0이다.

초기 데이터 및 조작: `Assets/CometFoundry/Docs/PlayableGuide.md`.

검증: 런타임 빌드 오류/경고 0. Unity 시뮬레이션 검증 통과. 신규 생산 EditMode 테스트 8개 통과(산업장비 5개 납품 목표 달성 포함). 초기 전체 실행 55개 중 50개 통과, 기존 혜성 생성·시장·의뢰 테스트 5개 실패는 가이드에 기록했다.

운송 배정은 빈 생산 입력을 우선 공급하고, 오래 기다린 건물에 한정된 가산점을 준다. 생산/판매/창고 우선순위는 유지하면서 특정 건물의 버퍼 보충으로 다른 생산 라인이 오래 대기하는 현상을 줄였다.
