# 거래소 차트 이미지 검토 및 수정

제공된 `거래소 현 이미지.png`에서 확인한 문제:

- 빨강/파랑 선이 연속 곡선 대신 작은 점과 조각으로 표시된다.
- 선 조각이 중앙 그래프 영역을 벗어나 우측 패널과 상단 HUD에 표시된다.
- 정가와 변동률 눈금이 그래프 위에 겹쳐 읽기 어렵다.
- 시간축이 음수 월 → 0월로 표기되어 과거 범위가 직관적이지 않다.

기존 IMGUI 선 그리기는 `GUIUtility.RotateAroundPivot`로 이미 배율을 적용한 화면 행렬을 회전시킨다. 제공 화면의 이탈 패턴과 해당 구현을 근거로 좌표 변환 문제를 판단했다. 이 방식을 제거하고 그래프 크기의 투명 텍스처 내부에 선을 직접 래스터화한다. 픽셀 경계 검사가 적용되어 차트 밖으로 그릴 수 없으며 그래프는 축과 동일한 Rect에 배치한다. 회전 행렬을 사용하지 않으므로 상단 HUD나 패널로 선이 퍼지지 않는다.

정가 0% 중앙선과 ±30%/±45% 규칙 및 빨강/파랑 색 구분은 유지했다. 가격 눈금을 왼쪽, 변동률을 오른쪽 외측 여백에 놓고 시간축에 ‘6개월 전 … 현재’ 상대 시간을 표시했다. 세로 보조선, 최신점 표시, 마우스 수직 가이드도 추가했다. 그래프 텍스처를 캐시해 매 GUI 이벤트에서 재생성하지 않고 불러오기/초기화 시 캐시를 무효화한다. 월 잔액 그래프도 같은 안전한 선 그리기 방식을 사용한다.

Unity EditMode 22/22 통과. 추가 검증은 정가 교차점 색 분리, 연속 대각선의 모든 픽셀 연결, 의도한 곡선 밖 투명 픽셀, 단일 월 잔액 점 렌더링이다. 실제 가격 데이터를 598×308 PNG로 출력하고 육안으로 연속선과 색 구분을 확인했다 (`Temp/FoundryValidationProject/ValidationArtifacts/exchange-chart.png`). Windows 빌드 갱신. 전체 게임 UI를 직접 재캡처한 검수는 자동 캡처 환경 제약으로 완료하지 못했다.
