# 거래소·혜성관리 확장

사용자 요청에 따라 거래소를 전 등급 수동 거래로 전환하고 좌측 재고/중앙 6·12·18·24개월 시세/우측 단가·수량·거래 확인 UI를 구현했다. 거래소 존재 여부로 HUD 거래소·혜성관리 버튼을 활성화한다.

혜성관리 소유 목록과 월 잔액 그래프, 기존 생성기를 사용하는 3개 후보 탐사, 비용 지불과 항구 자동 건설, 개발 구역 전환, 배경 생산, 수송선 구매와 혜성 간 물자 이동을 추가했다. 항구 만원 시 화물이 선박에 보존되며 공간 확보 후 부분 하역한다.

기본 시작 시설을 발전소·창고·채굴기 2개로 변경하고 실제 건설/생산/거래에 반응하는 9단계 튜토리얼을 구현했다. 흰색/주황색 항구 스프라이트를 추가했다. v2 저장은 모든 혜성과 수송·탐사·월 기록·튜토리얼을 보존하고 v1 읽기를 유지한다.

관련 Unity EditMode 18/18 통과. 에디터 검증 PASS 및 Windows 개발 빌드 성공. 기존 별도 시스템 테스트 전체의 알려진 실패는 이번 필터 실행에 포함하지 않았다. 자동 캡처 화면이 회색으로 렌더링되는 환경 문제 때문에 최종 UI 시각 검수는 미완료다.
