# 해상도별 UI 검증

검증일: 2026-10-14. Unity 6000.3.19f1, Windows 개발 빌드, Direct3D 11, 표시되는 창 모드로 검증했다. 열린 Unity 에디터는 유지하고 별도 사본에서 빌드·테스트했다. 원본과 검증 사본의 CometFoundry C# 소스 70개가 모두 일치한다.

## 결과

| --- | --- | ---: | ---: | --- |
| 1024x768 | 1024x768 | 63 | 8.53px | 통과 |
| 1280x720 | 1280x720 | 63 | 9.6px | 통과 |
| 1366x768 | 1366x768 | 63 | 10.24px | 통과 |
| 1280x1024 | 1280x1024 | 63 | 10.67px | 통과 |
| 1920x1080 | 1920x1080 | 63 | 14.4px | 통과 |
| 2560x1440 | 1920x1080 | 63 | 14.4px | 요청 크기 미검증 |
| 3440x1440 | 1920x1080 | 63 | 14.4px | 요청 크기 미검증 |

7회 실행, 총 441장 캡처. 실제로 서로 다른 5개 해상도에서 각각 63개 화면을 확인했다. 2560×1440 및 3440×1440 요청은 현재 실행 환경에서 1920×1080으로 생성되어 QHD·울트라와이드 시각 검증 완료로 판정하지 않는다. PNG 441장 전부의 실제 크기를 검사했다.

최종 실행 모두 런타임 오류 0건, 정상 종료. 캡처한 튜토리얼 화면의 타깃·팝업 화면 이탈 및 겹침 0건, GUIStyle.CalcHeight 기준 텍스트 높이 부족 경고 0건이다. 관련 EditMode 테스트 43개가 재실행에서도 통과했고 Windows 플레이 빌드를 갱신했다.

## 확인한 화면

타이틀, 튜토리얼 시작 선택, 개발 보드, 실제 정제소 생산 설정, 거래소 6·24개월 차트, 미션 목록 위·아래 스크롤, 마지막 5종 소재 미션 HUD, 10·11번 자산 보상 HUD, 혜성 탐사·수송선·철거 팝업을 캡처했다. 14개 튜토리얼 주제의 첫 단계와 건설·생산품 선택·차트·수송 설정·항구 재고 등 주요 단계도 확인했다.

63개 화면에 자동 레이아웃·텍스트 높이 검사를 적용하고, 실제 5개 해상도의 생산 팝업·차트·미션·수송 등 대표 화면을 직접 열어 시각 검토했다. 모든 441장을 개별 육안 검수한 것은 아니다. 초기 자금·시설·혜성·항구 재고를 준비한 검수 화면이므로 전체 튜토리얼의 실제 조작 완료 증거와 구분한다. 실제 행동 진행은 별도 EditMode 테스트에서 검증했다.

## 발견한 문제와 수정

1. 숨김 창 캡처는 검은 이미지였다. 표시되는 테스트 창으로 변경해 검수 가능한 화면을 확보했다.
2. Direct3D 캡처 이미지가 상하 반전되어 저장됐다. 텍스처 좌표 방향에 맞춰 저장 방향을 보정했다. 게임 화면 자체의 반전 문제는 아니다.
3. 기존 검증 시나리오가 정제소를 열지 않았다. 별도 검증 모드에서 실제 정제소와 레시피를 준비해 팝업을 열었다.
4. 혜성 자원 설명이 노드별로 같은 소재를 반복해 두 줄이 되면서 일부가 잘렸다. 보유·후보 혜성 모두 자원 종류별 잔량 합계로 표시하도록 수정했다. 초기 경고 5건이 수정 후 0건으로 줄었다.

## 가독성과 범위

UI는 1440×900 가상 화면을 비율대로 조정한다. 1024×768에서 작은 글씨는 약 8.53px, 1280×720에서는 약 9.6px로 줄어 설명과 보조 지표의 가독성이 낮다. 작은 해상도용으로 글씨를 키우는 별도 반응형 UI는 구현하지 않았다. 확인한 해상도 중 1920×1080이 가장 읽기 편했다.

이번 결과는 창 모드·Direct3D 11 기준이다. QHD·울트라와이드 실제 출력, 전체화면 전환, 실행 중 창 크기 변경, OS 배율별 표시와 모든 버튼의 실제 마우스 클릭은 포함하지 않는다.
